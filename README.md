# Palloma Depill

Landing page da Palloma Depill, depilação e massagem em Campina Grande, PB.

Site estático, sem etapa de build: `index.html` com CSS e JS embutidos, imagens em `img/`, Lenis (MIT) em `js/` para a rolagem suave.

## Publicar na Vercel

Importe este repositório na Vercel com **Framework Preset: Other**, sem comando de build e com a pasta raiz como saída.
